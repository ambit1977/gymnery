# Gymnery (トレーニング室アプリ)

Gymneryは、ジムでのトレーニングを効率的かつセキュアに記録するための、オフラインファーストなモバイル向けWebアプリケーション(PWA)です。

## 特徴

* **オフラインファースト**: すべての記録は端末内のローカルデータベース (IndexedDB) に保存されるため、電波の悪いジムの地下などでもサクサク動作します。
* **Google Sheets 自動同期**: あなたのGoogleアカウントを使ってログインすることで、自身のGoogle Drive上に専用のスプレッドシートを作成し、バックグラウンドで自動的にデータをバックアップ・同期します。
* **回復日数と成長判定**: 前回鍛えた部位の「中X日」の表示や、「前回より重量が上がったか（UP↑）」を一目で確認できるバッジ機能を搭載。
* **タイマーとプッシュ通知**: トレーニングセッションを開始するとタイマーが作動し、1時間経過前にPush通知で終了を知らせます。
* **PWA対応**: ホーム画面に追加することで、ネイティブアプリのようにフルスクリーンで動作します。

## 主な機能

* **ホーム**: 現在進行中のセッションや最近の履歴の確認、新しいトレーニングの開始。
* **マシン記録**: 部位別（胸、背中、脚など）または「今日のおすすめ（回復済み）」からマシンを選んで重量と回数をサクサク入力。インターバルタイマーも搭載。
* **履歴**: 過去のトレーニングセッションごとの詳細や、マシンごとの実施履歴（過去2週間等）の確認。
* **統計**: グラフ(Chart.js)を用いた、総セッション数や特定の部位・マシンの重量推移の可視化。
* **体組成**: 体重・体脂肪率の記録とグラフ推移。
* **設定**: スプレッドシート同期の設定や、施設・マシンの構成ファイル(JSON)の切り替え。

## 技術スタック

* **Frontend**: HTML5, Vanilla JavaScript, Vanilla CSS
* **Local Database**: IndexedDB (Dexie.js)
* **Cloud Database (Backup)**: Google Sheets API, Google Apps Script
* **Charts**: Chart.js
* **Hosting**: GitHub Pages
